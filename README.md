# Foggy v2 — объёмный наземный туман для Minecraft 1.21.1 (NeoForge)

Volumetric fog с привязкой к рельефу: полноэкранный raymarching-шейдер, который
«заливает» туманом низины и долины. Слой тумана лежит на сглаженном рельефе,
клубится (3D-шум), рассеивает свет в сторону солнца, наползает на рассвете
и тает днём.

## Стек

- Minecraft **1.21.1**
- **NeoForge** 21.1.244
- **ModDevGradle** 1.0.23, Gradle 8.10.2, Java 21

## Сборка и запуск

```bash
./gradlew build        # jar появится в build/libs/
./gradlew runClient    # запустить клиент для теста
```

## Команды

- `/weather fog` — включить туман на 5 минут (permission level 2)
- `/weather fog <длительность>` — ванильный формат: `30s`, `2m`, `600t`
- `/weather clear` — туман плавно рассеивается (~3 сек), естественный туман
  подавляется на 5 минут
- `/weather rain` / `thunder` — тоже гасят принудительный туман

## Как устроен рендер

1. **`VolumetricFogRenderer`** подписан на `RenderLevelStageEvent.AFTER_LEVEL`:
   после рендера мира рисуется полноэкранный квад с кастомным core-шейдером.
2. **Depth buffer** основного framebuffer'а копируется в отдельную текстуру
   (семплить привязанный depth нельзя) — из него шейдер восстанавливает
   мировую позицию каждого пикселя через обратные матрицы проекции и вида.
3. **Карта высот**: каждые 5 секунд CPU заполняет текстуру 128×128
   (2 блока/тексель, 256×256 блоков вокруг игрока):
   - R-канал — высота рельефа (`MOTION_BLOCKING_NO_LEAVES`),
   - G-канал — «пригодность» точки (влажный биом, не выше `maxAltitude`).
4. **Raymarch** (по умолчанию 24 шага, до 96 блоков): плотность в точке
   определяется высотой над рельефом. Верхняя граница слоя — *сглаженный*
   рельеф + толщина, поэтому туман заливает низины ровным «озером», а не
   повторяет каждый бугорок. Пер-пиксельный джиттер прячет бандинг,
   3D-шум даёт клубление и дрейф.
5. Цвет тумана берётся из ванильного fog color (на рассвете — розоватый),
   плюс форвард-скаттеринг в сторону солнца.
6. Сила тумана (время суток, погода, команды) сглаживается на CPU —
   переходы занимают несколько секунд.

## Ограничения для реализма

- пик на рассвете (22000–1500 тиков), днём тумана нет, ночью слабая дымка
- только влажные биомы (`hasPrecipitation`), порог температуры биома
- потолок по высоте `maxAltitude` (туман — явление долин)
- гроза почти разгоняет туман, дождь ослабляет
- под землёй и в пещерах тумана нет (проверка высоты рельефа)
- при `/weather fog` фильтры биомов снимаются, но привязка к рельефу остаётся

## Конфиг (`config/groundfog-client.toml`)

- `density` — плотность (экстинкция на блок)
- `thickness` — толщина слоя над рельефом
- `maxDistance`, `steps` — дальность и качество raymarch'а (производительность)
- `maxAltitude`, `maxBiomeTemperature`, `nightFog` — реализм

```
  net/ForcedFogPayload.java — пакет сервер->клиент

    FogShaders.java     — регистрация core-шейдера
    FogEnv.java         — сила тумана (время/погода) + сглаживание
    ClientFogState.java — состояние /weather fog на клиенте
    VolumetricFogRenderer.java — depth-копия, карта высот, полноэкранный проход
src/main/resources/assets/groundfog/shaders/core/
  volumetric_fog.json / .vsh / .fsh
```
